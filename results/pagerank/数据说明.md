## 数据内容说明

### 1. pagerank_performance_data.xlsx — 主数据文件

包含以下 5 个工作表（Sheet）：

| Sheet 名称 | 内容描述 |
|---|---|
| **PageRank性能对比** | AtSpMV vs cuSPARSE 在 10 个图数据集上的 PageRank 端到端性能对比，包含 Setup 时间、Iteration 时间、Total 时间及加速比 |
| **加速比汇总** | 按加速比降序排列的性能排名，含统计摘要（最大/最小/平均/中位数加速比） |
| **图数据集信息** | 10 个测试图数据集的详细元数据（节点数、边数、类型、来源、平均度数） |
| **测试平台与参数** | 实验环境、算法参数、对比方法等测试配置信息 |
| **SpMV底层性能(摘要)** | SpMV 底层算子性能数据摘要（前30行），完整数据见 spmv_performance/ 目录 |

### 2. 数据字段说明（PageRank性能对比表）

| 字段 | 单位 | 说明 |
|---|---|---|
| 图数据集 | — | SNAP/ SuiteSparse 图数据集名称 |
| 类型 | — | 图类型：Citation network / Collaboration network / Web graph / Vote network / Email network |
| 节点数 | 个 | 图中节点（顶点）总数 |
| 边数 | 条 | 图中有向边总数 |
| AtSpMV Setup (ms) | 毫秒 | AtSpMV 方法预处理/Setup 阶段耗时 |
| AtSpMV Iter (ms) | 毫秒 | AtSpMV 方法 PageRank 迭代阶段耗时 |
| AtSpMV Total (ms) | 毫秒 | AtSpMV 方法总耗时（Setup + Iter） |
| cuSPARSE Setup (ms) | 毫秒 | cuSPARSE 方法预处理/Setup 阶段耗时 |
| cuSPARSE Iter (ms) | 毫秒 | cuSPARSE 方法 PageRank 迭代阶段耗时 |
| cuSPARSE Total (ms) | 毫秒 | cuSPARSE 方法总耗时（Setup + Iter） |
| 加速比 | 倍 | cuSPARSE总耗时 / AtSpMV总耗时（值越大AtSpMV优势越明显） |
| 原始 (μs) | 微秒 | 原始数据（微秒），表中ms值 = 原始值 ÷ 1000 |

### 3. 关联关系

#### 数据与代码的关系

- **原始性能数据**：来源于 GPU 实测，运行 `build/pagerank` 和 `build/pagerank_atspmv` 可执行文件
- **绘图脚本**：[scripts/draw_pagerank.py](scripts/draw_pagerank.py) — 包含所有 10 个数据集的原始性能数值（单位：微秒）
- **生成脚本**：[scripts/generate_excel.py](scripts/generate_excel.py) — 将原始数据整理为结构化 Excel 的脚本
- **底层 SpMV 数据**：[spmv_performance/gpu_spmv_preconditioner_full.csv](spmv_performance/gpu_spmv_preconditioner_full.csv) — PageRank 每轮迭代核心操作为 SpMV（稀疏矩阵-向量乘），此文件包含 2009 个矩阵的 SpMV 预条件器性能完整数据

#### 数据与论文的关系

本数据集的 PageRank 性能对比实验关联以下研究工作的实验部分：
- **AtSpMV（Adaptive Tiled Sparse Matrix-Vector Multiplication）**：一种基于自适应分块和负载均衡的 GPU 稀疏矩阵-向量乘优化方法
- **对比基线 cuSPARSE**：NVIDIA 官方稀疏线性代数库（cusparseDcsrmv）
- 实验结论：AtSpMV 在 10 个图数据集上平均加速 **2.34x**（几何平均），最高加速 **4.18x**（wiki-Vote）
