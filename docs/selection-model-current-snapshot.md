# H100 选型效果快照

此快照记录 2026-10-30 的现有结果；逐矩阵状态和指标见 [数据表](../results/model/selection-model/snapshot-20261030/all-datasets.csv)，原始汇总见 [JSON](../results/model/selection-model/snapshot-20261030/summary.json)。未完成或未成功的矩阵按本次统计不可用处理，不计入性能平均值；待测不代表代码已被证明无法处理。

2888 张矩阵中，2797 张有有效结果（96.8%）。91 张本次不可用：49 张复数输入不支持、6 张非零元数超出 32 位索引、3 张输入无效、7 张超时、7 张报错、19 张未完成。运行仍可继续，后续结果不会改变本快照。

| 范围和选择方案 | 有效矩阵 | 相比 cuSPARSE 几何平均加速比 | 距已测最快候选 5% 以内 | 慢于已测最快候选超过 10% |
| --- | ---: | ---: | ---: | ---: |
| 校准范围内，vector v2 | 2248 | 1.594× | 1740（77.4%） | 294（13.1%） |
| 范围外，refined | 549 | 1.243× | 321（58.5%） | 108（19.7%） |
| 合计（两组不同选择方案） | 2797 | 1.518× | 2061（73.7%） | 402（14.4%） |

合计对两组几何均值按样本数加权，表示两个既有测试流程合并的统计，不能解释为同一模型在全部矩阵上得到的单一实验结果。每张矩阵比较同次计时中测得的候选，候选集合因测试批次而异；因此“最快”并非所有可能实现的全局最优。两种构造顺序的比值先取几何平均，再跨矩阵计算几何平均。测量为预热 CUDA Graph 执行，不含读取、Plan 初始化、选型及 Graph 构建成本。

在校准范围的 2248 张上，vector v2 六种宽度的时间比预测平均相对误差从旧版 9.12% 降到 6.45%；245 张按矩阵族近似划分的保留样本从 8.15% 降到 7.86%。同轮实际选中 Plan 相对旧版的几何平均加速比为 1.007×。数据和完整口径见 [验证记录](selection-model-validation.md)。

另一个默认关闭的 Graph 标签实验模型在全部 2248 张上的宽度时间比平均误差从 6.38% 降到 6.29%，同轮选中 Plan 相比 v2 仅 1.0007×；其中 1585 张属于训练/开发数据，剩余 663 张也曾在实验中查看。故不能据此保证对新矩阵的提升，也没有理由将其设为默认。离线绝对参考时间模型的平均绝对相对误差从 37.85% 降到 5.24%，但它不是实际 Plan 端到端实测。不同实验的计时和误差口径不同，不应直接比较其绝对值。
